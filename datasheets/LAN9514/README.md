## Ключевые характеристики (по datasheet)

- Интегрированный хаб USB 2.0, совместимый с USB 2.0 (3 внешних порта + Ethernet).
- Продвинутое энергосбережение (standby ~1 мкА, отключение портов).
- USB Battery Charger Detection.
- Ethernet 10/100 Мбит/с с встроенным PHY.
