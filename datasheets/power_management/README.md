## Важное уточнение про MxL7704

**MxL7704** (MaxLinear) подтверждён для Raspberry Pi 3 Model **B+** и Raspberry Pi **4** —
его нельзя автоматически включать в BOM исходной Raspberry Pi 3 Model B.
Фактическая микросхема управления питанием исходной 3B — **PAM2306AYPKE (U3)** +
**RT8088AWSC (U16)**, что подтверждено схемой RPI-3B v1.2.
Datasheet MaxLinear MxL7704: https://www.maxlinear.com (страница продукта MXL7704) —
доступ ограничен, требует проверки.

## Линии питания (по reduced-схеме)

`5V` (вход micro-USB) → `5V_CORE`, `VDD_CORE` (динамическое питание ядра SoC), `3V3`, `1V8`, `AUD_3V3`, `H5V` (питание HDMI). Сигналы управления: `RUN` (сброс/пуск), `SDRAM_LDO_EN`, `PWR_LOW_N`, `STATUS_LED`.

Точное распределение «преобразователь → линия» сверить по фото платы и полной схеме.
