# Реестр идентификации компонентов (Component Register)

**Объект:** Raspberry Pi 3 Model B, ревизия **1.2** (схема RPI-3B v1.2, © Raspberry Pi, 04.04.2016, James Adams)
**Метод:** идентификация по официальной электрической схеме `RP-008340-DS` + datasheets производителей.
**Дата заполнения:** 28.10.2026.

## 1. Порядок идентификации

1. По reduced-схеме RPI-3B v1.2 зафиксированы позиционные обозначения (U1, U3, U4, U9, U11, U14, U16, Q1, Q3, Q6, Q7, Q8, D1, D2, D5, F1, L1, L2, X1, J1, J4, J6, J8) и полные наименования компонентов.
2. Для каждого компонента найден datasheet производителя (см. `datasheets/` и `sources/references.md`).
3. Позиции, отсутствующие в reduced-схеме (U2 LAN9514, модуль BCM43438, память PoP LPDDR2), идентифицируются по официальной документации Raspberry Pi и по фотографиям конкретного экземпляра.

## 3. Ограничения и правила

- **MxL7704** подтверждён только для Raspberry Pi 3 Model **B+** и Pi 4 — в BOM исходной 3B не включается.
- Полные datasheets **BCM2837** и **BCM43438** не опубликованы Broadcom в открытом доступе; в `sources/references.md` зафиксированы использованные официальные документы и ограничение доступа.
- Линии питания по reduced-схеме: **5V, 5V_CORE, VDD_CORE, 3V3, 1V8, AUD_3V3, H5V**. Точное распределение (какой преобразователь формирует какую линию) сверить по фото платы и полной схеме, когда она будет доступна.
- Если маркировка не читается на имеющихся изображениях — идентификация подтверждается дополнительными фотографиями; поля не заполняются предположительными значениями (статус «Требует проверки»).

## 4. Что проверить по фотографиям исследуемой платы

1. Ревизия платы (надпись на PCB, например «Raspberry Pi 3 Model B V1.2») — влияет на все маркировки.
2. Верхняя сторона: LAN9514 (U2), PoP-память над BCM2837, BCM43438 у антенны, маркировки NC7WZ16 («P16»), DMG1012T/DMG2305UX.
3. Нижняя сторона: маркировка LPDDR2 PoP, расположение ключей и пассивных элементов.
4. Соответствие позиционных обозначений схемы расположению на конкретном экземпляре.
