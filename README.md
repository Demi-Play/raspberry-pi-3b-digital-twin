# Raspberry Pi 3 Model B — цифровой двойник

**Проект:** Реверс-инжиниринг и модернизация цифрового двойника Raspberry Pi 3 Model B
**Команда:** ИСИТ
**Участник (ИСИТ):** IT-специалист — анализ электронной компонентной базы
**Объект:** одноплатный микрокомпьютер Raspberry Pi 3 Model B (платформа BCM2837)

## Что уже сделано (ИСИТ)

1. Проанализирована **официальная электрическая схема** Raspberry Pi 3 Model B rev **1.2**
   (RPI-3B, схема «Reduced Schematics», drawing ref `RP-008340-DS`, © Raspberry Pi, 2016) —
   из неё извлечены фактические маркировки микросхем и позиционные обозначения.
2. Собраны и сохранены доступные **datasheets** производителей (см. `datasheets/`).
3. Сформирован **предварительный BOM-лист** (`bom/bom.csv`) с указанием статуса каждой позиции.
4. Заполнен **реестр идентификации компонентов** (`bom/component_register.md`).
5. Зафиксированы **геометрические параметры** платы по официальному механическому
   чертежу (`measurements/dimensions.csv`, drawing ref `RP-008335-DS`).
6. Составлен перечень **источников** с датами обращения (`sources/references.md`).

## Ключевые факты об аппаратной платформе

- SoC **Broadcom BCM2837**: 4 ядра ARM Cortex-A53 (Armv8, 64-бит, 1,2 ГГц) + VideoCore IV (400 МГц).
- ОЗУ **1 ГБ LPDDR2** в корпусе PoP (package-on-package), установленном поверх SoC.
- Питание: вход micro-USB 5 В; импульсные преобразователи **PAM2306AYPKE** и **RT8088AWSC**,
  супервизор **APX803-46SAG**, ключ **RT9741CGV** (линии: 5V, 5V_CORE, VDD_CORE, 3V3, 1V8, AUD_3V3 — по схеме RPI-3B v1.2).
- Сеть/USB: **SMSC (Microchip) LAN9514** — USB 2.0-концентратор (3 порта + Ethernet PHY 10/100).
- Беспроводная связь: **Broadcom BCM43438** — Wi-Fi 802.11n 2,4 ГГц + Bluetooth 4.1 (BLE); кварц 19,2 МГц (X1).
- Аудио/видео: двойной буфер **onsemi NC7WZ16** (U11) — аналоговый аудиовыход и композитное видео.
- Важно: SoC BCM2837 **снят с производства** (официальный PCN: `RP-001029-PC`); Pi 2B rev 1.1/1.2 — EoL c 16.10.2025.

## Ограничения исследования

- Полный datasheet Broadcom BCM2837 **не опубликован**; используется официальная документация и datasheet Broadcom BCM2835
  Raspberry Pi Foundation (периферия BCM2836/BCM2837) и ARM Cortex-A53 TRM.
- Полный datasheet BCM43438 **не опубликован**; используются официальные характеристики
  Raspberry Pi 3 Model B и электрическая схема.
- PMIC **MxL7704** относится к Raspberry Pi 3 Model **B+** и Pi 4 — в BOM исходной 3B **не включён**;
  фактическая схема питания 3B (PAM2306/RT8088/RT9741/APX803) подтверждена схемой RPI-3B v1.2.
